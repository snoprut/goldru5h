## GitHub Pages (anbefalet)
1. Opret nyt repo på GitHub (fx goldrush)
2. Upload ALLE filer fra denne mappe til roden af repoet
3. Settings → Pages → Source: Deploy from branch → main → / (root)
4. Åbn https://DIT-BRUGERNAVN.github.io/goldrush/

## Konti på flere devices
Konti gemmes i browserens localStorage på HVER enhed.
- Samme telefon/browser = samme konti
- Anden telefon = egne konti (de synkroniseres IKKE automatisk)

Rigtig synk på tværs af devices kræver en server/database (Firebase m.m.).

## Installer som app på mobil
1. Åbn siden i Chrome/Safari
2. “Føj til hjemmeskærm” / Install
